# Event night: pětiminutová kontrola

1. Dvakrát klikněte na `START_EVENT_NIGHT.cmd` a počkejte na potvrzení lokálního demo prostředí.
2. Přihlaste se zobrazeným lokálním admin účtem a spusťte `VERIFY_TONIGHT_GO_NO_GO.cmd`.
3. Pokračujte pouze při `GO — V2 SOFTWARE READY FOR PHYSICAL CHECK` a nulovém počtu blockerů.
4. Připojte HDMI, ve Windows zvolte **Rozšířit obrazovky**, otevřete projector window a zapněte fullscreen.
5. Ručně ověřte slyšitelné AUDIO, VIDEO s návratem na otázku a jeden RECAP od 0:00.

Při libovolném blockeru nebo selhání zvolte **NO-GO — USE V1** a ručně spusťte `OPEN_V1_FALLBACK.cmd`. Po práci vždy spusťte `STOP_EVENT_NIGHT.cmd`, aby se lokální data bezpečně exportovala.
